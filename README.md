# 财务管理智能体工作台 · 免费公开版

这是一个**单文件网页工具**：下载后用 Chrome / Edge 双击打开即可使用，不需要安装、注册、数据库，也不接 ERP 和银行流水。

## 这个版本是什么

- 13 个财务类目：出纳、成本、销售、总账、报价、预算、税务、资金、应收应付、固定资产、财务报表、费用报销、审计合规
- 每个类目都有「看板 + 表格 + 图表 + 解读」
- 支持 Excel / CSV 导入，带模板下载、列映射、科目映射、导入校验和完整校验报告
- 一个工作簿多张工作表会自动展开成多张待导入卡片，每张可单独选类目、改映射和写入方式
- 同一个工作表里并排或上下的多个表区也会自动拆开（“×× · 表区1 / 续页表”）
- 能识别常见的不规范格式：标题行、编制单位行、单位行、合并单元格、两行复合表头、重复表头、左右两栏资产负债表、无表头数据、月份/期间列
- 点“全不选”后，任意一张表都可以直接点“加入导入”恢复，不用重新上传
- 数据只保存在你自己的浏览器本地，不上传服务器；清空浏览器数据前请导出 JSON 备份
- 刷新页面后仍可从「更多 → 恢复历史快照」找回最近 5 次操作前的数据

## 这个版本不是什么

- 不是 ERP，不接总账系统、不接银行流水、不做自动记账
- 不是审计系统，校验结果只覆盖能在本机复算的结构与业务关联
- 不是多人在线协作版：同事之间不会自动共享数据，各自的数据在各自电脑上
- 公开版内置的是**脱敏示例数据**，不包含任何真实公司报表

## 部署到 GitHub Pages

1. 新建一个公开仓库，例如 `finance-workbench`。
2. 把本目录里的**全部文件**（含 `assets/`、`.nojekyll`、`robots.txt`）上传到仓库根目录。
3. 仓库 Settings → Pages → Source 选 `Deploy from a branch`，分支选 `main`，目录选 `/ (root)`。
4. 等 1–2 分钟，访问 `https://你的用户名.github.io/finance-workbench/`。

如果希望别人打开就能直接看到工具，把 `index.html` 保持在根目录即可；`assets/` 只影响配图和模板下载链接。

建议同时把 `assets/财务工作台_导入模板包.zip` 放到仓库里，公众号和小红书里可以直接给这个下载链接，省去逐个发文件。

## 分享时的建议说法

- 可以说：免费的单文件财务分析工作台，打开网页就能用，数据只存在自己电脑上。
- 可以说：支持把公司现有的 Excel 直接导入，系统先做结构和数据校验，确认后再写入。
- 不要说：接 ERP、接银行流水、自动记账、替代审计、永久免费无限更新。
- 不要展示任何真实公司名称、真实报表数字、真实客户名。

## 已知边界

- 一个工作簿可以一次展开多张工作表；每张表单独校验、单独确认。同一 Sheet 里的多表区会尽量自动拆分，但拆不开的复杂混排仍建议拆成“一表一 Sheet”。
- 没有表头的数据会自动补“科目编码 / 项目 / 金额……”占位列名，导入前请到“列映射”里改成真正的标准字段。
- 任意不规则 Excel 都不能保证 100% 自动识别，正确用法是「自动识别 → 看校验报告 → 人工确认 → 再导入」。
- 浏览器本地存储有容量上限，数据量大时请定期导出 JSON 备份。
